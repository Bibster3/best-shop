# Suitcase E-Shop

This project is a multi-page e-commerce website for a suitcase store. It is built using HTML, SASS, and vanilla JavaScript, with a focus on creating a responsive and interactive user experience without relying on external frameworks.

## Prerequisites

Before you begin, ensure you have [Node.js](https://nodejs.org/) and npm installed on your system.

## Project Setup

To get the project set up and running on your local machine, follow these simple steps.

1.  **Clone the repository** to your local machine.

2.  **Navigate into the project directory**:
    ```bash
    cd fundamentals-project-template
    ```

3.  **Install dependencies**:
    Run the following command to install all the necessary development dependencies listed in `package.json`.
    ```bash
    npm install
    ```

## Running the Project

To compile the SASS files into CSS and launch the project with a live server, you can use the `dev` script.

```bash
npm run dev
```

This command will start a local development server, and you will be able to view the website in your browser. The SASS compilation will be handled automatically.
